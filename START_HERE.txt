TextLink — START HERE
=====================

Product name: TextLink (messaging, connections, gifts — not Valentine-themed)

1. Local run
   pip install -r requirements.txt
   cp .env.example .env
   python3 app.py
   → http://localhost:5000

2. Before hosting
   Read HOSTING.md (required env vars, Postgres, Stripe, SMTP)

3. Deploy
   Read DEPLOY.md
   Push to GitHub → Railway/Render
   Set SECRET_KEY, FLASK_ENV=production, APP_URL, MAIL_*, STRIPE_*, DATABASE_URL

4. Make money
   Gifts + Premium + Boosts → your Stripe account → Payouts

Health check: GET /api/health
